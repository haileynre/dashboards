A registrant sees: a WebinarJam confirmation; their Close lead found or created (new records only are New Lead) with a Like LIVE activity; an ActiveCampaign contact on list 91 with a date tag and live-room link; a Google Calendar invite; and, if the phone is a US mobile, an SMS from automation 326 or 731. What must exist before someone registers

The zap finds calendar events and enrolls existing ActiveCampaign automations. It does not create either.

  1. EverWebinar #46 has a schedule for this Phoenix date and time.
  2. Five emoji events are on pace@subto.com, titles matching the Find Event searches. Create them from the Webinar Creation sheet (tab Make Webinars): one row per emoji, column K checked, then Calendar Events → Create or Update Selected Row.
  3. Per-run hardcodes in the zap match this date and title (tags, search terms, SMS cutoff).
  4. ActiveCampaign automations 326 (early) and 731 (late) are still the Like-Live SMS campaigns.
  5. The SDR roster Sub-Zap still returns the current list when called with Brand Subto.

EverWebinar #46

Email, name, phone, live room URL, webinar datetime, UTMs.

2 · Date

Arizona MM/DD/YYYY

From the webinar datetime, not from “now.” Feeds Close Notes and the tracker.

3 · Phone

Format + lookup

US to +1…, then Twilio carrier. Sets sms_safe.

4 · Close lead

Find or create

Match on email. Reuse if found. Create as New Lead only on a miss.

5 · Source

Update the lead

Last Source, Last Lead Type Webinar Registrant, Webinar Registration Lead Source.

6 · Activity

01. New Activity

Live edge. Funnel? Like Live. Notes Like Live Registration {date}.

7 · AC

List 91

Date tag + field 76 = live room. Extra (Email) tag when utm_medium is email.

8 · Calendar

One of five

Rotating 1–5. Find that emoji event. Add the registrant’s email as attendee.

9 · SDR

Owner or round robin

Owner already set → keep them. Empty → next SDR, then Slack + tracker.

10 · SMS

If sms_safe

Phone onto the SMS sheet. Before cutoff → automation 326. After → 731.

sms_safe = false does not fail the zap. Close, AC, calendar, and SDR still run. Only the SMS sheet and automations 326 / 731 are skipped.

Close — find or create, then the activity

Find or create by email. This is not a create-only step. If a lead with that email already exists, reuse it — never a second record. New Lead is the create default only; an existing lead keeps its current status. Source fields and 01. New Activity then write on whichever lead came back.
ResultWhat happens
Email already in CloseReuse that lead. Do not create another.
No matchCreate one as New Lead, type Webinar Registrant.

“Old lead” / “new lead” later in the zap means SDR Lead Owner already set or not, not find vs create. A found lead with an empty owner still goes through round robin.

ActiveCampaign

Old lead vs new lead

Old lead (SDR Lead Owner already set): tracker row labeled Old Lead, Slack the existing owner.

New lead (no owner): call the SDR roster Sub-Zap with Brand Subto, round-robin the next name onto SDR Lead Owner, Slack that person, tracker row labeled New Lead.

Google Sheets is a sink. Do not make the tracker authoritative for a new system.

Standing up a new replay date

Change the hardcodes. Do not clone the zap if you can avoid it — cloning is how we ended up with a dated copy per run. If you must clone, pause the old one in the same window.

  1. 1
    Confirm EverWebinar #46 has the new Phoenix schedule.
  2. 2
    Create the five emoji events on pace@subto.com from the Webinar Creation sheet. Titles must match the five Find Event searches.
  3. 3
    Open 371023152 and update together: AC tags ({M/D/YY} Bigger Like Live Registrant and the (Email) variant), the five Find Event search terms and date window, and the SMS cutoff ({Month DD}, 12:30 pm — 30 minutes before this run’s start).
  4. 4
    Test-register twice: a net-new email, and an email already in Close. Confirm find-or-create reused the existing lead (no duplicate).
  5. 5
    Then check, in order: Close lead + 01. New Activity → AC tag + field 76 → exactly one calendar attendee → Slack ping → tracker row → sms_safe on a real mobile → SMS sheet + automation 326 or 731.
  6. 6
    After the first live hour, group Close activities by Notes and AC tags by the new date string. Confirm the date is in the text — no Like Live Registration with a blank token.
