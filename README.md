# New Reach dashboards

Internal dashboards for New Reach. Each one lives in its own folder with its own README.

Published HTML is copied to [haileynre.github.io](https://github.com/haileynre/haileynre.github.io), which is the site at https://haileynre.github.io/. Pulse Backend and the September webinar status page live only on that site.

| Dashboard | Description |
|---|---|
| [`ar-outreach-dashboard/`](ar-outreach-dashboard/) | AR Payment Reminders - Outreach Dashboard (Subto): Google Apps Script web app showing AR reps' email/SMS outreach, open and response rates. New Reach Workspace accounts only. |
| [`webinar-new-activity-formats/`](webinar-new-activity-formats/) | Webinar "01. New Activity" field formats SOP: the Funnel/Notes text and date formats each brand writes for like-lives, true lives, lives and AMAs. Static HTML — open `index.html`. |
| [`webinar-replay-registration/`](webinar-replay-registration/) | Webinar Replay (Like LIVE) registration SOP for all six brands: shared flow plus EverWebinar numbers, Close workspaces, emoji sets, AC, SMS, SDR. Static HTML — open `index.html`. |
| [`change-calendar/`](change-calendar/) | Day-by-day log of Cursor changes: platform, what changed, and downstream impact. Static HTML — open `index.html`. |
| [`tc-like-live-attribution/`](tc-like-live-attribution/) | TC LIKE-LIVE registrations vs. Top Tier Close Signed Up within 7 days of watching. Snapshot November 9, 2026. [Live page](https://haileynre.github.io/tc-like-live-attribution/). |
| [`like-live-attribution/`](like-live-attribution/) | Comparison of the brand like-live attribution pages. Top Tier, Zero Down, and Deal Scout are live. [Live page](https://haileynre.github.io/like-live-attribution/). |
| [`ds-like-live-attribution/`](ds-like-live-attribution/) | DEAL SCOUT LIKE-LIVE (#54) registrations in 2026 vs. Deal Scout Close Signed Up within 7 days of watching. [Live page](https://haileynre.github.io/ds-like-live-attribution/). |
| [`zdb-like-live-attribution/`](zdb-like-live-attribution/) | ZDB LIKE-LIVE (#48) registrations in 2026 vs. Zero Down Close Signed Up within 7 days of watching. [Live page](https://haileynre.github.io/zdb-like-live-attribution/). |
| [Pulse Backend tab](https://haileynre.github.io/pulse-backend-tab/) | Spec for the NR Pulse Backend tab: setup checklist and read-only webinar lead test. Hosted on the public site. |
| [Zoom webinar automation status](https://haileynre.github.io/nre-webinar-status/) | September 2026 status of the Zoom webinar move from Zapier to n8n. Hosted on the public site. |
