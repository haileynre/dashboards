Webinar Replay registration SOP

What happens when someone registers for a Like LIVE (Webinar Replay) — and what changes per brand. Same shape for all six: find or create the Close lead, write 01. New Activity, upsert ActiveCampaign, add them to one emoji calendar copy, then SMS if the phone is safe. Tags, EverWebinar numbers, Close workspaces, emoji sets, and who assigns the SDR are brand-specific.

Who this is for

Ops / MarTech

Stand up the next replay date — hardcodes plus the emoji events — before ads go live. Use the brand table so you change the right EverWebinar number, tag, and emoji set.

Anyone debugging

Trace a registrant who missed a tag, invite, SDR, Slack ping, or SMS. Start with the shared flow, then the brand row.

Anyone writing Close

These zaps write the live-edge 01. New Activity. Most still use the historical Like LIVE strings. Prop.ai already writes the Oct 8 Webinar Replay - MM/DD/YYYY standard.

A registrant sees: confirmation (WebinarJam or ClickFunnels), their Close lead found or created (new records only are New Lead) with a Replay activity, an ActiveCampaign contact with a date tag and room link, a Google Calendar invite, and — if the phone is a US mobile — an SMS. On Subto and Deal Scout the assigned SDR also gets a Slack ping. On the other four brands, SDRs are assigned manually after the webinar has ended.

What must exist before someone registers

The zap finds calendar events and enrolls existing ActiveCampaign automations. It does not create either.

  1. The brand’s EverWebinar number(s) have a schedule for this Phoenix date and time. Multi-day: every day has its own webinar ID.
  2. Emoji events are on pace@subto.com, titles matching that brand’s Find Event searches. Create them from the Webinar Creation sheet (tab Make Webinars): one row per emoji, column K checked, then Calendar Events → Create or Update Selected Row. Prop.ai is 4 emojis; everyone else is 5.
  3. Per-run hardcodes in that brand’s zap match this date and title (tags, search terms, SMS cutoff).
  4. The brand’s early / late SMS automations (or Close outbox number) are still the Replay campaigns.
  5. Subto and Deal Scout only: the SDR roster Sub-Zap still returns the current list for that brand.

What happens when someone registers

Shared path. Brand-specific values (webinar number, Funnel/Notes, AC list, emoji set, SMS, SDR) are in By brand.

1 · Trigger

Register

Five brands: EverWebinar register. Prop.ai: ClickFunnels contact, then API-register onto each day’s webinar ID.

2 · Gates

Brand filters

Gator drops a registration if the webinar date is already past. Gator and ZDB wait 2 minutes before writing Close.

3 · Phone

Format + lookup

US to +1…, then Twilio carrier. Sets sms_safe.

4 · Close lead

Find or create

Match on email in that brand’s Close workspace. Reuse if found. Create as New Lead only on a miss.

5 · Activity

01. New Activity

Live edge. Funnel + Notes strings differ by brand. Lead Type is Webinar.

6 · AC

List + date tag

Create or update. Live-room (and sometimes replay) custom fields. Extra (Email) tag when utm_medium is email.

7 · Calendar

One emoji copy

Rotating slot. Find that emoji event on pace@subto.com. Add the registrant’s email as attendee.

8 · SDR

Two patterns

Subto + Deal Scout: owner or round robin, then Slack. Everyone else: assigned manually after the webinar.

9 · SMS

If sms_safe

Enroll in that brand’s early / late automation, and/or send from the brand’s Close outbox number.

sms_safe = false does not fail the zap. Close, AC, calendar, and (where used) SDR still run. Only the SMS sheet and SMS automations / Close texts are skipped.

Close — find or create, then the activity

Find or create by email. This is not a create-only step. If a lead with that email already exists in that brand’s workspace, reuse it — never a second record. New Lead is the create default only; an existing lead keeps its current status. 01. New Activity then writes on whichever lead came back.
ResultWhat happens
Email already in that Close orgReuse that lead. Do not create another.
No matchCreate one as New Lead, type Webinar Registrant.

“Old lead” / “new lead” later in the Subto and Deal Scout zaps means SDR Lead Owner already set or not, not find vs create. A found lead with an empty owner still goes through round robin.

01. New Activity — live edge

38 writers, one listener. Do not rename these strings as a drive-by. The Oct 8 standard says new writes should be Webinar Replay - MM/DD/YYYY — see the Funnel? SOP. Only the Prop.ai Replay zap already writes that. The other five still use the historical Like LIVE Funnel / Notes pair.

Standing up a new replay date

Change the hardcodes on that brand’s classic zap. Do not clone the zap if you can avoid it — cloning is how we ended up with a dated copy per run. If you must clone, pause the old one in the same window.

  1. 1
    Confirm the brand’s EverWebinar number has the new Phoenix schedule. Multi-day (Prop.ai): confirm both day codes.
  2. 2
    Create the emoji events on pace@subto.com from the Webinar Creation sheet. Titles must match that brand’s Find Event searches (emoji set + this run’s title token). Four events for Prop.ai, five for everyone else.
  3. 3
    On that brand’s classic zap, update together: AC tags ({M/D/YY} … Registrant and the (Email) variant when the brand has one), the Find Event search terms and date window, and the SMS cutoff.
  4. 4
    Test-register twice: a net-new email, and an email already in that Close workspace. Confirm find-or-create reused the existing lead (no duplicate).
  5. 5
    Then check, in order: Close lead + 01. New Activity → AC tag + room field → exactly one calendar attendee → tracker row → sms_safe on a real mobile → SMS path. Subto / Deal Scout: Slack ping with an owner.
  6. 6
    After the first live hour, group Close activities by Funnel / Notes and AC tags by the new date string. Confirm the date is in the text — no blank token.

Out of scope

Other webinar types

Live Zoom, AMAs, Fireside Chats, NOLB / Swoogo — different zaps.

Attendance outcomes

Attendee, Non Attendee, Left Early, Saw CTA — staff update those in Close by hand after the replay.

Creating the emoji events

Webinar Creation sheet, not this zap.

The SMS body

Lives in that brand’s ActiveCampaign automations (or the Close SMS template).
